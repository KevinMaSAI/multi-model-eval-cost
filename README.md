# 多模型评测与成本分析器

一个零依赖的中文评测工具：将同一批题目发送给多个 OpenAI 兼容模型，比较回答、评分、延迟、token 和按配置价格计算的费用。

## 文件

- `index.html`：完整静态单页，CSS、JavaScript、SVG、Canvas 均内嵌，没有 CDN、分析脚本或远程依赖。
- `server.js`：仅使用 Node.js 内置 http / https 的本地代理。

## 本地使用

1. 双击 `index.html`，用现代浏览器打开。也可用任何静态服务器提供该文件。
2. 配置至少两个模型：显示名称、Base URL、API Key、Model ID、输入和输出单价。预设是参考配置，模型是否可用需以你的账号为准。
3. 添加题目或批量导入 JSON / CSV / 一行一题的纯文本。题库与模型配置会自动保存。
4. 选择评分方式、并发数、请求间隔，点击“开始评测”。调用会产生 API 费用；不会自动重试。
5. 查看回答对比、排行榜和成本分析；需要时人工覆盖评分。
6. 导出 CSV 台账后再刷新页面或开始新一轮。结果不长期保存，配置、题库、价格保存在 localStorage 中。

浏览器禁止本地存储时仍能临时使用，但关闭页面后配置会丢失。file:// 页面的存储行为由浏览器决定；不同地址、浏览器和设备不共享配置。

## 为什么需要本地代理

浏览器会阻止未允许跨域的 API 请求。代理从本机发出请求，将响应原样交回前端，并添加浏览器需要的 CORS 响应头。

先安装 Node.js 18 或以上版本，在本项目文件夹打开终端运行：

```sh
node server.js
```

默认地址为 `http://localhost:3000/proxy`。在前端勾选“使用本地代理”。代理仅绑定 `127.0.0.1`；如本机 localhost 的 IPv6 解析导致连接失败，将页面里的代理地址改为 `http://127.0.0.1:3000/proxy`。

覆盖端口（Windows PowerShell）：

```powershell
$env:PORT = '3001'
node server.js
```

Ubuntu / macOS：

```sh
PORT=3001 node server.js
```

同时把前端代理地址改为对应端口。按 Ctrl+C 停止代理。代理总超时为 120 秒，前端超时也可设置；代理模式实际受两者较短值限制。

前端发送 `POST /proxy`，在 `X-Target-URL` 中传递完整 `/chat/completions` 地址，通过 `Authorization` 携带 Bearer Key。代理不解析请求体，透传响应状态和响应体（包括 usage、401、429）；OPTIONS 返回 204；连接错误返回 502。日志仅打印目标 origin、路径、状态和耗时，不打印 Key、请求体、响应体或查询参数。中途断流可能导致响应不完整，前端会展示错误。

## 部署到 GitHub Pages

1. 创建 GitHub 仓库，将 `index.html` 放在仓库根目录并提交。不要上传密钥或带密钥的配置文件。
2. 打开仓库 Settings → Pages，选择从分支部署（Deploy from a branch），选择包含文件的分支和 `/ (root)`，保存。
3. 部署完成后，将 GitHub 提供的 Pages 地址发给别人即可打开页面。

GitHub Pages 只托管前端，不能运行 Node.js 代理。每位使用者填写自己的 Key，并在自己的电脑启动代理；如供应商支持 CORS，可关闭代理直连。HTTPS 页面访问本机 HTTP 代理取决于浏览器的本地网络权限和安全策略，允许相应提示后再试；若仍被拦截，下载 HTML 本地打开，或通过本地静态服务器使用。不要通过关闭浏览器全局安全策略解决问题。项目交付不代表已创建仓库或部署线上站点。

## 评分口径

- 精确匹配：去掉回答与参考答案的首尾空白后比较，相同为 10，否则为 0；不自动删除标点、解释或代码围栏。
- 关键词：参考答案可用 `|`、逗号、分号或换行分隔；去重后，按不区分大小写的子串命中比例 × 10 计分。
- LLM 裁判：用指定模型输出 0–10 分 JSON 与理由。裁判费用独立记账，包含在全局汇总及 CSV 中。裁判可以是未启用参与评测的已配置模型。
- 无参考答案时，前两种方式留空；裁判可以独立判断。API 错误、裁判失败、无效裁判 JSON 留作未评分，不当作错误答案打零分。
- 总分为已评分回答之和；平均分与正确率（≥6 分）以已评分条数为分母。请结合成功率、评分覆盖率判断排名。
- 性价比 = 总分 / 模型回答总费用；不含裁判费用。费用为零或无评分时显示“—”。不同覆盖率或缺失用量下不能直接比较。
- 可人工覆盖评分。模型内容可能诱导裁判错误，自动评分仅供评测参考，不会执行生成的代码。

## Token 与价格表

优先读取 `usage.prompt_tokens`、`usage.completion_tokens`、`usage.total_tokens`。输入 / 输出都有但总量缺失时直接相加；输入或输出缺失则只对缺失部分使用轻量字符规则估算，并标为“估算值”。该估算不是官方 tokenizer，可能有明显误差。原始 usage 会进入 CSV。

```text
费用（USD）= 输入 token / 1,000,000 × 输入单价
            + 输出 token / 1,000,000 × 输出单价
```

内部按未舍入值累加，界面显示四位小数，CSV 导出未舍入费用。请求失败且没有 usage 时费用未知，不能认为是零：已送达、超时或取消的请求仍可能在服务商侧计费。全局费用包含所有已知回答与裁判费用；未知部分明确标注。并发限制也适用于裁判请求，请求间隔是所有调用共用的最小启动间隔。

下列为需求指定的默认参考值（美元 / 百万 token），**价格可能变动，以官方为准，可手动修改**：

| Model ID | 输入 | 输出 |
|---|---:|---:|
| gpt-4o | 2.5 | 10 |
| gpt-4o-mini | 0.15 | 0.6 |
| o3-mini | 1.1 | 4.4 |
| deepseek-chat | 0.27 | 1.1 |
| glm-4-plus | 0.7 | 0.7 |
| qwen-plus | 0.4 | 1.2 |
| moonshot-v1-8k | 1.7 | 1.7 |

在模型配置中改价会保存到本地；每条调用保留当时的价格快照，不追溯修改历史费用。实际 token 不等于账单已核验：缓存命中、阶梯价格、折扣、工具费用、税费等未单独建模，最终以服务商账单为准。请勿把估算记录当作真实用量。

## 安全提示与故障排查

- **密钥仅保存在本地浏览器**；请求会携带密钥发往你填写的服务商或本地代理。localStorage 不是加密保险箱，同源脚本、扩展和本机用户可能读取。仅使用信任的页面和端点；不要在共享电脑保留 Key。删除模型可移除该配置，或清除此站点浏览器存储。
- **代理只在本机运行，不存储密钥，不要部署到公网**。它按需求允许 `Access-Control-Allow-Origin: *`，属于无认证转发服务；运行时不应访问不可信网站，使用后停止。不要通过隧道或反向代理公开它。
- 输出纯文本展示，不解析模型 HTML。CSV 对公式开头内容加前置单引号，减少表格软件公式执行风险；导出包含题目和回答，分享前检查敏感内容。
- 401 / 403：检查 Key、权限和端点；429：检查余额或限流并降低并发。404：确认模型 ID 和 Base URL 路径。不要把服务错误计入能力失败。
- DNS / TLS / 超时：检查网络、接口地址和系统证书；代理返回 502，不会自动禁用证书验证。
- 无 usage：界面显式显示估算；若需要可核对的 token 数据，请使用会返回 usage 的接口。
- 停止仅中断本地等待与后续调度，不能保证撤销已送达的上游请求。

## 验证范围

自动化验证通过本地模拟 OpenAI 接口覆盖 token、费用、评分、导入、CSV 和代理错误透传。真实 API Key 需由使用者在本地填写后验收；本项目不包含密钥，也不声称完成真实付费调用或 GitHub Pages 发布。
