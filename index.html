使用说明

  1. 这个工具做什么：将同一批题目发给多个模型，比较回答、评分、token 和费用。
  2. 使用步骤：配置模型与价格 → 准备题库 → 运行 → 看回答与 token / 花费 → 看排名 → 导出 CSV。运行一轮会替换上一轮结果，请先导出。
  3. 密钥安全：API Key 只存本地浏览器 localStorage；请求直接发往你配置的服务商或本地代理。不把密钥发送给页面作者。不要在共享电脑使用；浏览器扩展、同源脚本可能访问本地存储。删除模型即可删除该配置中的密钥。
  4. API 兼容：填写 OpenAI 兼容 Base URL（如 https://api.openai.com/v1）或完整 /chat/completions 地址。请求使用非流式 messages；各厂商模型可用性以账号为准。
  5. 花费口径：输入 token × 输入单价 / 1e6 + 输出 token × 输出单价 / 1e6。优先读取 usage；缺失字段用轻量估算并标明。总 token 缺失但输入 / 输出完整时直接相加。费用按单价计算，并非服务商账单：缓存、阶梯价、优惠、工具附加费等会造成差异。内部不四舍五入，展示 4 位小数；小于 $0.0001 的正值另有提示。裁判调用另记账并计入全局费用。
  6. 常见问题：CORS 报错：运行 node server.js 并开启代理，必要时允许浏览器访问本地网络；若浏览器仍拦截，可用本地静态服务器打开页面。Key 无效：核对密钥、权限、余额和地址。无 usage：显示“估算值”，不能用于核账。价格更新：在模型配置中手动修改；修改不改变已完成记录的价格快照。429：降低并发、增大间隔；本工具不自动重试。

LLM 裁判可能被回答内容误导，评分应人工复核；可在回答卡片中输入 0–10 分覆盖自动评分。停止会中断本地请求，但已送达服务商的请求仍可能计费。
